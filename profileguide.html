Aksar pooche jaane wale sawal

Mera username "already taken" bol raha hai, ab?

Koi dusra username chuno, jaise naam_skill ya naam123. Profile step mein bhi aap username badal sakte ho, wahan turant dikh jata hai ki available hai ya nahi.

Verification code nahi aaya to?

30 second ruko, phir Resend Code dabao. Prototype mode mein code screen par hi dikhaya jata hai (asli email/SMS nahi jata).

Mere paas college email nahi hai, kya kar sakta hu?

Koi dikkat nahi. Step 7 par college ID number daal do (manual review ke liye) ya "Verify later" dabao. Baad mein college email se verify kar sakte ho.

Phone number dena zaruri hai?

Nahi, ye optional hai. "Skip for now" dabao. Lekin verified phone se trust badhta hai aur fake accounts kam hote hain.

Meri private info kisi ko dikhegi?

Nahi. Email default mein hidden rehta hai, aur Step 17 mein aap decide karte ho ki profile Public, Campus Only ya Private rahe. Ghar ka address kabhi nahi manga jata.

Profile baad mein edit kar sakte hain?

Haan. Preview page par har section ke saamne Edit button hota hai, aur baad mein bhi settings se badal sakte ho.
